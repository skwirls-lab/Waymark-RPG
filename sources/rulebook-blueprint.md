# Cairn Multiverse Standalone Rulebook Blueprint

**Status:** Structural blueprint only. This is not rules text and does not yet claim a complete, playable system.  
**Project requirement:** The final book must be fully rewritten and self-contained. It must explain every core rule and every included optional module in full, so players and Wardens do not need the Cairn SRD or Sylvanholt rules document at the table. Source documents remain development references for comparison, provenance, and attribution research.  
**Related:** [[Cairn-Multiverse-Project-Vision]] · [[Cairn-Multiverse-Rules-Audit]] · [[Cairn-Multiverse-Rule-Disposition-Matrix]] · [[Cairn-Multiverse-Universal-Expansion-Prototype-v0.1]]

## Book architecture principles

- **One complete Core Rules path:** a new group can create characters and play without choosing any optional module.
- **Modules are complete:** each optional module states its purpose, prerequisites, procedures, character-sheet needs, compatibility interactions, and what it replaces or adds.
- **Setting-neutral rules first:** keep universal procedures separate from Sylvanholt lore and from future setting packs.
- **Templates alongside rules:** teach readers how to create content using explicit prompts, examples, and review checks.
- **Reference-ready:** tables, quick procedures, glossary, sample characters, and character record instructions are included in the book.
- **Clear provenance:** identify original/adapted material and provide verified Cairn attribution and licensing information before publication.

## Proposed table of contents

### Front matter

1. **Title, version, and credits**
2. **What this game is** — concise pitch, intended play experience, and relationship to Cairn
3. **How to use this book** — Core Rules vs Optional Modules vs Setting Packs; module notation and compatibility labels
4. **What you need to play** — players, dice, character records, tokens, maps/minis if desired
5. **A note on source and license** — final wording pending verification of source edition, exact text reused, license, attribution, and share-alike requirements

### Part I — Core Rules (complete default game)

1. **Core principles** — fiction first, player agency, caution, teamwork, Warden neutrality, clear information, telegraphed danger
2. **The play loop** — describe situation, ask questions, state intent, determine whether a roll is needed, resolve, apply consequences, update the fiction
3. **Dice and saves** — dice notation, ability scores, roll-under procedure, natural 1/20, advantage/disadvantage if retained, when to roll and when not to
4. **Character creation** — step-by-step baseline creation, abilities, HP, identity/background/traits, starting gear, name/description, starting resources
5. **Inventory and equipment** — slots, hands/body/backpack, bulky/bundled items, full inventory, Fatigue, carrying beyond personal capacity, equipment use
6. **Time, movement, and distance** — exploration time, turn structure, movement units, selected tabletop scale, movement actions, extra movement, terrain, range, zones/grid/ruler alternatives
7. **Exploration and procedures** — travel, light, supplies, searching, hazards, watches/encounters, rest and safe/unsafe conditions (as selected)
8. **Combat** — encounter start, intention telegraphing, initiative/turn order, movement and actions, attacks, damage, Armor, impaired/enhanced attacks, dual/group attacks, Blast, morale, retreat
9. **Harm, HP, critical damage, and scars** — HP meaning, exactly 0 HP, damage beyond HP, ability loss, 0-score outcomes, baseline injury table, stabilization, recovery
10. **Deprivation, Fatigue, rest, and healing** — needs, deprivation triggers, resource-slot interaction, clearing Fatigue, HP and ability recovery, treatment
11. **NPCs, reactions, morale, hirelings, and groups** — concise Warden procedures and stat conventions
12. **Treasure, rewards, and growth** — campaign rewards and emergent advancement; make explicit whether and how the selected Cairn-derived advancement rules work
13. **Warden procedures** — adjudication, danger, preparation, random tables/Die of Fate, NPC motivations, consequences, campaign continuity
14. **Player principles** — questions, agency, planning, caution, teamwork, ambition
15. **Core bestiary and conversion guidance** — universal stat block, creating threats, damage and Armor guidance, morale, special effects
16. **First session and sample play** — complete sample character creation and a short annotated play example

### Part II — Optional and Expanded Modules

Each module repeats a standard opening: *What it changes; when to use it; what it requires; what it replaces; how it interacts with Core Rules; player/warden reference card.*

1. **Origins and Lineages** — reusable identity packages; biological, cultural, geographic, occupational, and technological origins; creation template
2. **Powers** — defined abilities with effect, scope, limits, cost, risk, and recovery; Sylvanholt-derived pressure/cost approach; compatibility notes
3. **Power cost profiles** — Fatigue, consumables, charges, exposure, time, consequences, or no explicit cost; rules for choosing and tracking a cost
4. **Cairn spellbook compatibility option** — separate implementation for groups wanting spellbooks/scrolls/relics; fully described if included so the book stays self-contained
5. **Structured advancement** — optional milestones, ranks, capacity, and character growth tracks; distinguish from core emergent advancement
6. **Alternate injury and scar tables** — tone and setting variants; compatibility with ability loss and recovery
7. **Corruption, stress, contamination, or transformation** — triggers, escalation, symptoms, treatment, and end states selected by a campaign
8. **Item modification and crafting** — process, prerequisites, costs/catalysts, risks, bounded effects, example setting implementation
9. **Movement and tabletop scale options** — selectable scale cards, compact table, larger table, abstract range/zones, and movement-action choices; exact tested procedures
10. **Genre/scale options** — technology, horror, heroic/superheroic scope, vehicles, unusual environments as supported by playtest
11. **Cohort, hireling, detachment, and campaign-scale options** — only where they differ materially from baseline

### Part III — Make-Your-Own Workshop

1. **How to customize without breaking the game** — a brief design loop: concept, scope, procedure, cost/risk, compatibility check, playtest, revise
2. **Create an Origin** — form, prompt questions, boundary guidance, examples
3. **Create equipment** — inventory, damage/Armor, charges, reliability, cost/availability, examples
4. **Create a Power or spell** — effect, target, range, duration, limits, cost, risk, recovery, examples
5. **Create an enemy/NPC** — stat-block template, danger/HP/Armor guidance, morale, behavior, special consequence
6. **Create a condition, hazard, or corruption track** — trigger, warning, procedure, stakes, exit/treatment
7. **Create a setting module** — required fields, compatibility declarations, substitutions and optional layers
8. **Balance without point-buy** — scope tiers, opportunity cost, frequency, counterplay, fictional constraints, test prompts
9. **Worked examples** — Sylvanholt Note, ordinary scout, science-fiction augment, superheroic ability, custom equipment

### Part IV — Settings and examples

1. **Sylvanholt setting pack** — world introduction and setting-specific character creation, tribes/origins, Ardenfire Powers, Noctimancy/corruption, equipment, crafting, campaign principles, bestiary, glossary; all needed setting rules included locally
2. **Additional genre examples** — short sample modules (e.g. medieval low-fantasy, science-fiction exploration, heroic/superheroic) only after core interfaces stabilize
3. **Conversion examples** — translate broad character concepts, not every copyrighted character; demonstrate scope and boundaries

### Appendices and play aids

- One-page Core Rules reference
- Character sheet and instructions
- Campaign scale card / movement setup card
- Origin, equipment, Power, NPC, and setting-module templates
- Quick tables: reactions, morale, injuries, encounters, treasure, and other retained procedures
- Conditions and terms glossary
- Worked examples and sample campaign start
- Licensing, attribution, version history, and feedback/playtest record

## Content status labels for drafting

Use these tags in working drafts until decisions are finalized:

- **CONFIRMED DIRECTION:** user-established project goal or preference.
- **SOURCE RULE:** accurately extracted from a named reference document; not automatically a final adopted rule.
- **PROPOSED CORE:** intended baseline, still requiring review/playtest.
- **OPTIONAL MODULE:** a complete elective procedure.
- **SETTING RULE:** applies only in the named setting pack.
- **OPEN DECISION:** unresolved; do not write as settled.
- **PLAYTEST NOTE:** observation, not yet a design rule.

## Initial drafting sequence

1. Build a complete source/disposition ledger from the Cairn reference and Sylvanholt rules: retain, adapt, optionalize, setting-only, omit, or open decision. Preserve source locations and flag all mismatches.
2. Decide the minimum complete default play experience and terminology. Do not draft every optional system before Core Rules are coherent.
3. Draft Core Rules in this book’s own language, including every procedure needed for a first session. Avoid “see Cairn” or “as in the Sylvanholt rules.”
4. Add module boundaries and compatibility notes while drafting; keep proposed rules labeled until reviewed.
5. Draft the movement/scale module after verifying the exact Cairn edition/source and John’s current table procedure.
6. Develop Origins, Powers, equipment templates, and worked examples; test across genre and power scales.
7. Add Sylvanholt as the first full setting pack, preserving its established lore while aligning terminology and explicitly documenting any rule changes.
8. Playtest complete Core Rules with no optional modules, then playtest each module and its interactions.
9. Verify completeness, internal consistency, licenses/attribution, and reader usability; then prepare publication and app-ready structured data.

## Completeness gate before calling it a full ruleset

A group unfamiliar with the sources must be able to:

- create a character using only this book;
- understand what each ability and resource does;
- explore, travel, and adjudicate time/movement at the chosen scale;
- run a complete combat encounter and resolve harm, recovery, and retreat;
- create and run ordinary NPCs, threats, and rewards;
- understand advancement and all default campaign procedures;
- select, enable, and use an optional module without hunting for rules elsewhere;
- customize an Origin, item, Power, threat, or setting element using the included guidance; and
- play the Sylvanholt setting with the complete setting pack, without needing the legacy rules document.

If any item requires an external source or an unwritten ruling, the standalone rulebook is not complete yet.
