# WAYMARK — BUILDER'S GUIDE

Forms and advice for making your own content. Nobody needs this to play.

## Four checks for anything you make

1. **Can you explain it in two sentences?** If not, cut it down.
2. **What ordinary gear is it like?** It should be about as useful as that gear.
3. **When does it apply?** Strong things should apply in specific situations. Things that are always on should be mild.
4. **Would every player take it?** Then it is too good.

Never add a roll to hit, never push Armor past 3, and never add flat bonuses to damage. Use impaired (d4) and enhanced (d12) instead.

## An Origin

```
NAME:
WHO THEY ARE: (two sentences)
BONUS: +1 to STR / DEX / WIL
TRAIT: In ________, you can ________.
DRAWBACK (only if the Trait is strong):
STARTING KITS (optional): d6 table of weapon, armor, tools
```

Ask: what can these people do that would surprise an outsider? Where are they most at home? What do they need that others do not?

## An Affinity and its Powers

```
AFFINITY NAME:            WHAT IT IS ABOUT:
POWER:
  DOES: (one or two sentences, with any numbers)
  REACH: self / touch / nearby / at range / an area
  LASTS: instant / a few rounds / ten minutes
  CANNOT:
```

Write about four Powers per Affinity. Try to give each Affinity one that harms or hinders, one that protects or mends, one that reveals, and one that reshapes the scene.

| A Power that... | Should be about this strong |
|---|---|
| Harms one target | d6 or d8 |
| Harms an area | d6 Blast |
| Heals | Restore 1d6 STR, or clear one ailment |
| Protects | +2 Armor to those nearby for a few rounds |
| Controls | Target saves or is held, turned, or stopped briefly |
| Reveals | One clear answer, or senses extended for a minute |
| Reshapes | A wall, bridge, or barrier of 10–20 feet |

Every Power costs the same, so they should all be worth about the same. If one only does what a cheap tool does, make it better.

## A piece of gear

```
NAME:
SLOTS: small / 1 / 2 (bulky)
WEAPON d__  or  ARMOR __  or  TOOL
WHAT IT LETS YOU DO:
COST:
```

Pick a weapon's die by how it is carried: improvised d4, light d6, one-handed d8, two-handed d10. Ranged weapons run one step lower for their size. Nothing a person carries starts at d12.

## A creature

```
NAME.  __ HP, __ Armor, __ STR, __ DEX, __ WIL, attack (d__).
WHAT IT IS LIKE:
WHAT IT WANTS:
WHEN IT WOUNDS SOMEONE BADLY:
HOW THE PLAYERS SEE IT COMING:
```

HP 3 ordinary, 6 tough, 10+ serious. A d6 attack is dangerous in numbers. A d8 can drop a new character in two rounds. A d10 or a Blast can kill in one, so make it obvious.

## A world

A world is a short document that fills in the blanks the rulebook leaves:

```
[ ] Pitch: the place, the threat, what characters do
[ ] Which Modules are on
[ ] Origins and their starting kits
[ ] What Powers are called, the Affinities, and their Powers
[ ] Tier names and the deeds that earn them
[ ] Corruption: names, carriers, places of safety
[ ] Crafting: sites, catalysts, qualities
[ ] Gear names and prices
[ ] Creatures
[ ] What a typical mission looks like
[ ] Move distance, if using miniatures
```

See `settings/Sylvanholt.md` for a complete example.
