# Waymark

A roleplaying game for any world, written for people who have never played one. Based on *Cairn* by Yochai Gal (CC BY-SA 4.0), with Origins, Powers, Affinities, Tiers, corruption, and imbued gear generalized from *Sylvanholt: The First Song*.

**Status:** draft 0.3, unplaytested. "Waymark" is a working title.
